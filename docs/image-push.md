# 主动图片推送

Web 管理台的「图片推送」用于向一个群、多个群或当前所有已登记群发送图库图片。手动批次和自动计划共用同一个队列，并保留逐群结果。

## 图片分配

- **固定相同图片**：填写一个 `PID[:页码]`，所有可发送群使用同一作品和页面。
- **固定不同图片**：为当前目标群分别填写 PID。动态所有群模式下，后来加入且没有映射的群会被跳过并告警。
- **随机相同图片**：按目标群中最严格的分级限制抽取一张图片，所有群使用同一作品和页面。
- **随机不同图片**：每个群按自己的分级限制独立抽取图片和页面。

省略页码时随机选择页面；例如 `12345678:2` 指定第 2 页。固定 PID 不在图库中时，系统会自动从 Pixiv 导入完整作品后再发送。

发送会遵守群组启用状态、`allow_setu`、`sanity_limit` 和 `allow_r18g`。不可发送群会单独标记为跳过，不阻止其他群继续。

批次会记录每个群的最终 PID、页码、Telegram 消息 ID、重试次数和原因；状态包括排队中、执行中、成功、部分成功、失败、全部跳过、结果不确定和已取消。预检查发现群停用、机器人不在群内或没有发图权限时记为 `skipped`；真实发送返回错误时记为 `failed`；超时或进程中断导致无法确认是否送达时记为 `uncertain`，不会自动重复发送。

## 自动计划

计划支持一次、每日、每周和固定间隔（60 秒至 30 天）。周期使用计划时区；所有执行时间会转换为 UTC 保存。选择“所有群”时，每个批次开始执行时重新读取当前群组列表。

同一机器人的批次按创建顺序排队。Telegram 明确限流时最多按服务端等待时间重试 3 次；超时或网络结果不确定时不会自动重发。进程中断后的发送会标记为“不确定”，需要人工核查。

## Telegram 命令

`/push` 或 `/push random` 在当前群随机推送；`/push 12345678` 推送指定 PID，`/push 12345678:2` 推送指定页面。命令仅限超级管理员在群内使用。跨群推送和自动计划请使用 Web 管理台。
